# Iris guides

For a first installation, [start with the optional-feature map](start-here.md),
then follow the complete [Windows](setup-windows.md), [macOS](setup-macos.md) or
[Ubuntu](setup-linux.md) route. Each gets one conversation working before adding
the Pi, phone and chosen extras.

For the curious, [how Iris works](technical-guide.md) explains the underlying
ideas as well as the implementation. Use the [interface map](interfaces.md),
[settings reference](configuration-reference.md) and [verification map](verification.md)
when you need the details. The [reference setup](reference-setup.md) distinguishes
reported hardware from combinations that still need validation.
